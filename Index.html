    Email templates

    Write {first} for the contact's first name ("there" if there isn't one) and {company} for the company name. Each lead gets its type's default template automatically: Opening for new leads, Follow-up once emailed, Final after a follow-up. You can still pick any template when emailing.

    Export

    Import

    Choose an Excel or CSV file to add leads. The first row needs column names, at least Company or Email. Matching emails update existing leads instead of duplicating them, and a status is never set back to Not contacted.
